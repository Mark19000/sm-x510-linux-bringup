# U11 Pipeline Code Audit — 2026-08-23

## Scope and Method

Static audit and local reproduction, without editing or deleting sources or artifacts. Reviewed `build-osrc-u11-in-lima.sh`, `build-u11-kernel-guest.sh`, `build-u11-initramfs.sh`, and preflight/module wrappers; ran Bash syntax checks, 15 tests with `unittest`, module audit, and preflight with output directed to `/tmp`. Did not re-run full kernel build. `shellcheck` and `pytest` were not installed.

Reproduced results:

- `bash -n`: all scripts pass.
- `python3 -m unittest discover -s tests -p 'test_u11*.py'`: **15/15 OK**.
- Module audit: PASS on stock provenance, metadata/vermagic/signature of 282 modules, hard graph, relative order, and UFS/USB closures; WARN for obsolete softdeps mirrored from stock, USB lacking host mode, and absent Wi-Fi/BT firmware.
- Preflight: rc=0, offline analysis `READY`, M3 payload `READY`; 12 PASS and 5 WARN. Key warning is lack of valid comparison of two clean runs for current artifact.
- Spot check: `SHA256SUMS` of active build (15 files) and initramfs (9 files) OK; all nine patches match `configs/u11-patches.sha256`.
- Reports regenerated to `/tmp` were byte-identical to existing ones (`preflight.json` SHA-256 `ac437d0b…985cb`; `modules-audit.json` `2cd35378…4e4b5`), confirming determinism of these offline analyzers.

## Findings

| # | Severity | Finding | Evidence | Proposed Patch |
|---:|---|---|---|---|
| 1 | **High** | Module packaging fails or is non-portable due to GNU tar option ordering: `--no-recursion` is placed after `-cf -` and before `--files-from=-`. In preserved fixed1 test it exited with `status=2` because tar treated it as operand/error; in fixed2/fixed3 it emitted a warning and omitted recursion. | `scripts/build-u11-kernel-guest.sh:175-177`; `artifacts/u11/x510xxsbdzb4-u11-fixed1-20260823/u11-build.log:8238-8240`; STATUS fixed1 `status=2`. | Move all options before redirection/operands: `tar --null --no-recursion --sort=name --mtime=@0 --owner=0 --group=0 --numeric-owner -C "$modules_stage" -cf "$DIST/modules-root.tar.gz" --files-from=-`. Robust alternative: generate NUL list and use Python/TarFile or `bsdtar`. |
| 2 | **High** | Active build lacks provenance evidence generated by active recipe or valid comparison of two runs. Its log corresponds to an earlier inspection (`mode=inspect`), while `BUILD_INFO.txt` references `inspect4` and old recipe paths (`u11-patched`, `build-patched`). `reports/generated/u11-repro/reproducibility.json` does not exist; fixed2 and fixed3 differ in Image/System.map/tar. Preflight correctly reports WARN, but M3 gates declare payload READY relying solely on initramfs. | `BUILD_INFO.txt` of directory `x510xxsbdzb4-u11-clang21-20260823`; hashes fixed2 vs fixed3 (`Image` `4cc882ef…` vs `8e79d90d…`; `System.map` `8b3a5ab6…` vs `6dc904e6…`; tar `7f8aa59c…` vs `1afd3481…`); preflight WARN `kernel_binary_reproducibility`; absence of `reports/generated/u11-repro`. | Regenerate canonical artifact with active recipe from two fresh run IDs, run `u11_repro_compare.py`, and archive JSON/MD before exposing as preflight base. Add explicit requirement of repro report PASS to gate M3 if payload must be release-grade. |
| 3 | **Medium** | Manifest validation evadable with symlinks: `verify_checksum_file()` uses `candidate.relative_to(directory)` on an unresolved `Path`. A symlink can point outside; in this case it is reported as "missing", but if the external target exists and matches, check passes even though verified content is not under the tree. Also fails to detect duplicate entries or extra files. | Controlled reproduction in temp: manifest `link -> ../outside/secret`, matching hash ⇒ result `([], [])`. Code in `tools/u11_preflight.py:81-104`. | Reject `candidate.is_symlink()`, verify `candidate.resolve().relative_to(directory.resolve())`, record duplicates, and compare actual inventory against manifest to detect extras. |
| 4 | **Medium** | TOCTOU race between creation and guard of host run: `mkdir "$host_run"` occurs before `guard_output_directory`; a local attacker can replace the new directory with a symlink before guard/copies. Guard resolves symlinks (proven), but too late to avoid writing to redirected destination. | `scripts/build-osrc-u11-in-lima.sh:176-182`; local test showed a run symlink is accepted after resolving to target. | Create with `mktemp -d "$HOST_RUNS/${RUN_ID}.XXXXXX"` and rename atomically to final ID after validation, or open directory with protected descriptor and validate `/dev/fd`; ideally use parent with restricted permissions. |
| 5 | **Medium** | Overlay selection based on README grep permits incorrect overlays if multiple markers or incidental text exist, and does not validate full identity (model/variant/hash) of overlay. Uniqueness only covers eligible READMEs; a second ZIP with identical text but different content can alter the composite. | `scripts/build-osrc-u11-in-lima.sh:272-292`: searches any `README*`, requires two strings, and applies `cp -a --remove-destination`. | Identify overlay by expected name/path and SHA-256 hash declared in identity; then validate markers. Record hash of each applied file and reject more than one candidate per path/hash, not just per README. |
| 6 | **Medium** | Inspect mode silently accepts absence of U11 overlay and exits success. This facilitates preserving/evidencing "U11" when only U8 base exists. Build mode does require it. | `scripts/build-osrc-u11-in-lima.sh:293-295`: message "Exact overlay not found..." without failure; STATUS inspect=0. | In U11 mode, require exactly one overlay in inspect mode as well; separate explicit optional `base-only` mode with unambiguous label. |
| 7 | **Medium** | Incorrect assumption in initramfs: assumes the only child under `MODULES_ROOT` is the release and requires exactly 282 `.ko`, but does not verify they are regular until count (`find -type f` excludes symlink, leaving ambiguous error) nor checks freshness/provenance against active build. Can validate a stale tree if it retains 282 modules and internal hashes. | `scripts/build-u11-initramfs.sh:53-69`; initramfs `BUILD-METADATA` declares `byte_reproducible=yes` only for profiles, without binding hash of source kernel/modules-root. | Save and require `source_modules_root_sha256` / hash of `modules-root.tar.gz` in initramfs metadata; list non-regular files and fail with clear cause; include U11 build provenance in `BUILD-METADATA`. |
| 8 | **Low/Medium** | Preflight treats `initramfs_usb` as PASS even if it does not fit (`fits=false`) because profile is flagged diagnostic; `m3_payload_ready` gate uses only minimal/ufs, but PASS state can confuse automation and human readers. | `tools/u11_preflight.py:357-362`; reproduced output: LZ4 3,018,036 B, margin −531,234 B, check PASS. | Use `WARN` status for oversized diagnostic profile, or add field `packaging_ready=false` and exclude from PASS-based aggregations. |
| 9 | **Low/Medium** | Build determinism depends on clang-specific flags: Clang 21 warnings are suppressed dynamically and debug prefix maps entire `RUN_ROOT`, not just run component. Changing compiler/run parent still alters binaries; furthermore active `BUILD_INFO.txt` admits incremental LTO was not bit-reproducible. | `scripts/build-u11-kernel-guest.sh:110-119`; active `BUILD_INFO.txt`: first link `3218ae0d…`, final different. | Pin exact version/toolchain and toolchain hash; map `/$(basename RUN_ROOT)` or copy to constant canonical path; document that ARM64/clang 21 compatibility is not equivalent to Samsung reproducibility; require two clean builds. |
| 10 | **Low/Medium** | Evidence export tolerates silent failures: each failed `limactl copy` only emits a warning, including `STATUS`, manifests, and build log. Exit code can then be zero with incomplete evidence. | `scripts/build-osrc-u11-in-lima.sh:434-445`; loop ignores failures with warning. | Require `STATUS` and log always; on successful build require all manifests and dist; classify failures as fatal or write `EXPORT-INCOMPLETE` and return non-zero code. |
| 11 | **Low** | Run concurrency competes on guest paths only if same `RUN_ID` is forced; host avoids overwrite, but creates host run first and then `mkdir -p` on guest without atomic exclusion. Two invocations with same ID can both pass initial validation and manipulate distinct/overlapping guest paths depending on timing. | Host `mkdir` at line 179; guest `mkdir -p "$guest_run/input"...` line 207. | Create guest run with atomic `mkdir` and fail if it exists; synchronize selection/creation on both sides before copying inputs. |
| 12 | **Low** | `u11-preflight.sh` and `u11-modules-audit.sh` always write fixed reports inside repo without locking or temporary option; two concurrent executions can interleave final temporary files (writes use `os.replace`, but JSON/MD pairs can desynchronize). Also impedes read-only audit without touching repo. | `scripts/u11-preflight.sh:6-10`, `scripts/u11-modules-audit.sh:4-6`; `atomic_write` in tools. | Support `--output-dir`/env var, fail-if-exists, or stdout mode; use a lock per report path and publish JSON/MD pair via staging directory rename. |
| 13 | **Low** | Key tests are textual and do not exercise complete shell semantics: they verify substrings such as options, names, and guards. This lets bugs like the actual `tar` ordering found in logs slip through. | `tests/test_osrc_u11.py:185-228`; `tests/test_u11_preflight.py:91-101`. | Add integration tests with stubs for `limactl`/`make`/`tar` capturing argv, and unit test for expected tar command; run ShellCheck in CI. |

## Positive Observations

- Design prevents arbitrary build commands, rejects `.part` and U3 checkout as input, keeps staging on ext4, and preserves physical NO-GO gate.
- Extractor handles traversal, collisions, special types, limits, and parent symlinks better than native archive extraction.
- Initramfs pipeline verifies double execution and normalizes timestamps/owners; offline analyzers are deterministic upon local repetition.

## Suggested Priority
